// THE WORKFLOW

从想做，到能做。
一条龙跑通。

上架前最容易卡壳的4个环节，每一步都有对应的skill。一套用下来，新品决策从"凭感觉"变成"看数据"。

01 / 初筛
⚖️
类目五维评分
amazon-category-scorer

需求密度、评论壁垒、利润结构、差异空间、供应链难度。一个类目能不能做，先打分，再决策。

02 / 调研
🔍
类目深度调研
amazon-market-research

市场规模、竞争格局、价格带、目标人群、中小卖家切入方案。一份完整的调研报告，少走3个月弯路。

03 / 上架
✍️
Listing 撰写
amazon-listing-writer

按 A10、COSMO、Rufus 三套系统逻辑写，标题5点描述、后台词、移动端短描述，直接能用。

04 / 视觉
🎨
商品图 Prompt
amazon-image-prompt

主图、生活方式图、痛点图、卖点图、规格图、对比图，6张图的英文Prompt一次出齐，喂给AI生图工具。
