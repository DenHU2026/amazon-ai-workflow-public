# 亚马逊-东哥的 AI 工作流

## 这是什么

亚马逊上架前的最后一公里，全部交给AI。

**4个skill串起一条完整闭环：**

| 顺序 | Skill | 用途 |
|------|-------|------|
| 01 | `amazon-category-scorer` | 类目五维评分，要不要做这个类目 |
| 02 | `amazon-market-research` | 类目深度调研，怎么做这个类目 |
| 03 | `amazon-listing-writer` | Listing撰写，标题5点描述一次出 |
| 04 | `amazon-image-prompt` | 商品图Prompt，6张图一次出齐 |
